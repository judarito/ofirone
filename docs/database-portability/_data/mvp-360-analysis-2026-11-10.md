# Análisis 360 del MVP

## Estado local Go

- Auth, tenant y menú: operativo.
- Productos, clientes, inventario y ventas: endpoints disponibles y frontend con flags.
- Compras: dominio Go creado con validación de totales; falta repositorio y endpoint transaccional.
- Dashboard/reportes: todavía dependen de servicios frontend/Supabase; no hay contrato Go MVP cerrado.

## Diferencias Supabase vs PostgreSQL portable

- Supabase tiene `purchases`, pero no `purchase_lines`; usa `purchase_order_lines` y
  tablas adicionales de cuentas por pagar.
- PostgreSQL portable ya tiene `purchases` y `purchase_lines` normalizados.
- No se debe copiar SQL de compras directamente: requiere adaptador de columnas,
  estados, proveedores y líneas.
- CXC de clientes y cuentas por pagar de proveedores son dominios distintos y no
  deben compartir saldos por accidente.
